# PowerBI_phonepe_analysis
This project presents an interactive PhonePe Transaction Analysis Dashboard to analyze digital payment trends, transaction success rates, service performance, and failure reasons across multiple categories. The dashboard enables users to explore transaction insights through dynamic filters, KPIs, and visual storytelling to support decision-making.
PhonePe Pulse Data Visualization & Analysis
​📊 Project Overview
​This project is a comprehensive analysis of PhonePe Pulse data, focusing on transaction trends and user growth across India. The goal was to transform raw JSON data into an interactive dashboard that reveals geographical and temporal patterns in digital payments.
​🚀 Key Features
​Interactive Map: Visualizing transaction amounts and counts across all Indian states and districts.
​Transaction Analysis: Breakdown of payment types (Peer-to-peer, Merchant payments, Recharges, etc.).
​User Demographics: Tracking app installs and registered users over time.
​Dynamic Filtering: Filter data by Year and Quarter to see growth trends.
​🛠️ Tech Stack
​Tool: Power BI Desktop
​Data Source: PhonePe Pulse GitHub Repository
​Techniques: Data Cleaning (Power Query), DAX Measures, Geo-spatial Mapping.
